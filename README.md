# 🏛️ BUNYAN Tech | بُنيان للحلول البرمجية والتجارة الإلكترونية

منصة رسمية متطورة لشركة **بُنيان للحلول البرمجية والتجارة الإلكترونية**، مبنية بمعمارية حديثة متعددة الصفحات (Multi-Page Architecture) مستوحاة من أفضل البوابات العالمية (Toyota.com) وتجمع بين الهيبة المؤسسية والمرونة البيعية الذكية.

---

## ✨ المميزات الرئيسية للموقع (Key Features)

- **🏛️ معمارية متعددة الصفحات (Multi-Page Architecture)**: إلغاء التمرير الرأسي الأحادي الطويل؛ كل قسم وخدمة تمتلك صفحتها الخاصة بروابط نظيفة وسريعة.
- **🚗 تشكيلة الحلول البرمجية (Solutions Lineup Selector)**: مستوحاة من أداة استعراض فئات السيارات في تويوتا، مع تبويبات تفاعلية تستعرض الفئات (المتاجر، السحابة والـ SaaS، مواقع الشركات، الأكاديمية) مع الأسعار المبدئية والمواصفات.
- **⚡ حاسبة بناء وتسعير المشروع التفاعلية (Build & Price)**: أداة ديناميكية تمكن العميل من اختيار نوع مشروعه وتخصيص المزايا والإضافات لمعرفة التكلفة والمدة التقديرية لحظياً.
- **🌗 نظام مظهر مزدوج فائق التباين (Dark / Light Mode)**: تباين لوني معتمد وفق معايير WCAG AAA مع خطوط Cairo وPlus Jakarta Sans.
- **💬 تكامل واتساب مباشر**: أزرار اتصال فوري وحجز استشارات تقنية سريعة.
- **🛡️ الشفافية والسياسات الرسمية**: صفحة مستقلة تعرض سياسة التعديلات، ضمان الصيانة المجاني لمدة 6 أشهر، وعقود الإنجاز الموثقة.

---

## 📂 هيكلية الصفحات (Pages Structure)

| الصفحة | المسار | الوصف |
|---|---|---|
| **الرئيسية** | `index.html` | بوابة الاستقبال الرئيسية مع شريط تشكيلة الحلول ونماذج المشاريع وبانر Build & Price |
| **خدماتنا والحلول** | `services.html` | تفاصيل المتاجر الإلكترونية، المنصات السحابية SaaS، أنظمة ERP، وهندسة واجهات UI/UX |
| **معرض الأعمال** | `portfolio.html` | دراسات الحالة المفصلة (التحدي التقني، الحل الهندسي، وأرقام النتائج) |
| **أكاديمية بُنيان** | `academy.html` | معسكر Full-Stack التدريبي (16 أسبوعاً) مع المنهاج ونموذج التسجيل |
| **كيف نعمل والسياسات** | `process.html` | مراحل العمل الأربعة وسياسات الضمان وضمان الصيانة 6 أشهر وشروط التعاقد |
| **التسعير وبناء المشروع** | `pricing.html` | أداة Build & Price التفاعلية ومقارنة باقات الأسعار المعتمدة |
| **تواصل معنا** | `contact.html` | حجز استشارة تقنية مجانية، اتفاقية سرية (NDA)، وقنوات التواصل المباشر |

## 🚀 التشغيل محلياً (Run Locally)

المشروع مبني بـ HTML5، CSS3 الحديثة، وJavaScript الأصيل دون أي مكتبات ثقيلة لضمان أعلى سرعة ممكنة (Core Web Vitals 99/100).

```bash
# تشغيل خادم محلي خفيف
node server.js
```

ثم فتح المتصفح على:
`http://127.0.0.1:3000`
